# HomeParty

## Назначение

HomeParty - сервис для организации домашних праздников.

Приложение помогает пользователю планировать мероприятие, учитывать участников,
задачи по подготовке и расходы.

## Целевая аудитория

Люди, которые самостоятельно организуют домашние праздники, дни рождения,
семейные мероприятия и встречи с друзьями.

## Предметная область

Предметная область проекта - организация домашних праздников.

Сервис позволяет планировать событие, учитывать его участников,
контролировать задачи по подготовке и отслеживать расходы.

## Основные сущности

- событие;
- участник;
- задача;
- расход.

## Основные функции

- получение информации о событии;
- проверка количества участников;
- проверка бюджета мероприятия;
- добавление участников;
- управление задачами подготовки;
- учет расходов.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
