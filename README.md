# HomeParty

HomeParty - учебное консольное приложение для организации домашних праздников.

Проект разрабатывается в рамках практических работ по дисциплине
«Технологии разработки приложений на базе фреймворков».

## Описание проекта

Приложение позволяет работать с домашними событиями, участниками, задачами
подготовки и расходами.

В ПР3 проект был переведен с функциональной модели на объектно-ориентированную.

## Основные классы

### Event

Класс `Event` представляет событие.

Основные атрибуты:

- `id` - идентификатор события;
- `name` - название;
- `date` - дата;
- `budget` - бюджет.

Основные методы:

- `is_budget_enough()` - проверка, хватает ли бюджета;
- `__str__()` - строковое представление события.

### Participant

Класс `Participant` представляет участника события.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `name` - имя участника.

Основные методы:

- `__str__()` - строковое представление участника.

### Task

Класс `Task` представляет задачу подготовки события.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `title` - название задачи;
- `completed` - признак выполнения.

Основные методы:

- `complete()` - отметить задачу выполненной;
- `__str__()` - строковое представление задачи.

### Expense

Класс `Expense` представляет расход.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `title` - название расхода;
- `amount` - сумма.

Основные методы:

- `__str__()` - строковое представление расхода.

## Взаимодействие объектов

Объекты `Participant`, `Task` и `Expense` связаны с объектом `Event`.

Пример:

```text
Participant -> Event
Task        -> Event
Expense     -> Event
