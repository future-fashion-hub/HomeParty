# HomeParty

HomeParty - учебный проект для организации домашних праздников.

Проект разрабатывается в рамках практических работ по дисциплине
«Технологии разработки приложений на базе фреймворков».

## Описание проекта

Приложение позволяет организовать домашний праздник и хранить информацию
о событиях, участниках, задачах подготовки и расходах.

Основные сущности проекта:

- событие;
- участник;
- задача;
- расход.

## Возможности приложения

В текущей версии реализованы:

- просмотр списка событий;
- добавление нового события;
- поиск события по названию;
- сортировка событий по дате;
- добавление участников;
- подсчет количества участников события;
- добавление задач подготовки;
- отметка задач как выполненных;
- просмотр невыполненных задач;
- добавление расходов;
- подсчет общей суммы расходов;
- проверка соответствия расходов бюджету;
- сохранение данных в JSON-файлы;
- загрузка данных из JSON-файлов при запуске;
- обработка некорректного пользовательского ввода.
