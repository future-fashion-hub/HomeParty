# HomeParty

HomeParty - учебное приложение для организации домашних праздников.

Проект разрабатывается в рамках практических работ по дисциплине
«Технологии разработки приложений на базе фреймворков».

## Описание проекта

Приложение позволяет планировать домашние события, вести список участников,
контролировать задачи подготовки и учитывать расходы.

В ПР3 проект был переведен на объектно-ориентированную модель. В ПР5 к
существующей консольной версии добавлен веб-интерфейс на Django 5.2. Классы,
JSON-хранилище, тесты и консольная точка запуска сохранены.

## Возможности веб-интерфейса

- главная страница с навигацией по разделам;
- список событий и подробная страница события;
- просмотр участников, задач и расходов;
- динамические URL с числовыми идентификаторами;
- ответы с кодом 404 для отсутствующих объектов;
- адаптивное оформление на Bootstrap 5.3.

## Страницы и URL

| Страница | URL | View-функция |
| --- | --- | --- |
| Главная | `/` | `homepage.views.index` |
| События | `/events/` | `events_app.views.event_list` |
| Событие | `/events/<id>/` | `events_app.views.event_detail` |
| Участники | `/participants/` | `participants_app.views.participant_list` |
| Задачи | `/tasks/` | `tasks_app.views.task_list` |
| Расходы | `/expenses/` | `expenses_app.views.expense_list` |

## Основные классы

### Event

Класс `Event` представляет событие.

Основные атрибуты:

- `id` - идентификатор события;
- `name` - название;
- `date` - дата;
- `budget` - бюджет.

Основные методы:

- `is_budget_enough()` - проверка, хватает ли бюджета;
- `__str__()` - строковое представление события.

### Participant

Класс `Participant` представляет участника события.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `name` - имя участника.

Основные методы:

- `__str__()` - строковое представление участника.

### Task

Класс `Task` представляет задачу подготовки события.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `title` - название задачи;
- `completed` - признак выполнения.

Основные методы:

- `complete()` - отметить задачу выполненной;
- `__str__()` - строковое представление задачи.

### Expense

Класс `Expense` представляет расход.

Основные атрибуты:

- `id` - идентификатор;
- `event` - объект `Event`;
- `title` - название расхода;
- `amount` - сумма.

Основные методы:

- `__str__()` - строковое представление расхода.

## Взаимодействие объектов

Объекты `Participant`, `Task` и `Expense` связаны с объектом `Event`.

Пример:

```text
Participant -> Event
Task        -> Event
Expense     -> Event

Связи объектов сохраняются в JSON через `event_id`. Django-view загружают
эти данные существующими функциями из `storage.py` и формируют HTTP-ответы.

## Структура Django-проекта

```text
HomeParty/
├── homeparty/          # настройки и корневая маршрутизация
├── homepage/           # главная страница и общий HTML-каркас
├── events_app/         # страницы событий
├── participants_app/   # страница участников
├── tasks_app/          # страница задач
├── expenses_app/       # страница расходов
├── models/             # объектная модель ПР3
├── data/               # JSON-файлы
├── tests/              # тесты предметной логики и веб-маршрутов
├── manage.py
└── main.py             # сохраненная консольная версия
```

## Установка и запуск

```powershell
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py runserver
```

После запуска приложение доступно по адресу
`http://127.0.0.1:8000/`.

Консольная версия запускается отдельно:

```powershell
python main.py
```
